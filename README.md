# 💰 Expense Tracker - Приложение для учёта расходов и доходов

Полноценное веб-приложение для личного учёта финансов с frontend на React, backend на Node.js/Express и базой данных SQLite.

## 📋 Описание

Expense Tracker — это современное приложение для управления личными финансами, которое позволяет отслеживать доходы и расходы, анализировать траты по категориям и контролировать свой бюджет.

## ✨ Функциональность

### Основные возможности:
- ✅ **Добавление транзакций** — доходы и расходы с указанием названия, суммы, категории и даты
- ✅ **Редактирование записей** — изменение любой транзакции
- ✅ **Удаление операций** — с подтверждением действия
- ✅ **Расчёт финансов** — автоматический подсчёт общего дохода, расходов и текущего баланса
- ✅ **Фильтрация** — по типу операции (доход/расход), категории и периоду дат
- ✅ **Статистика по категориям** — визуальный график расходов и доходов
- ✅ **Адаптивный дизайн** — корректное отображение на компьютерах, планшетах и смартфонах
- ✅ **Валидация данных** — проверка корректности ввода на клиенте и сервере
- ✅ **Постоянное хранение** — все данные сохраняются в базе данных SQLite

### Категории:
**Доходы:** Зарплата, Фриланс, Инвестиции, Подарки, Другое

**Расходы:** Еда, Транспорт, Жильё, Развлечения, Здоровье, Одежда, Образование, Другое

## 🚀 Установка и запуск

### Предварительные требования:
- **Node.js** версии 14 или выше
- **npm** или **yarn**

### Шаг 1: Клонирование репозитория
```bash
git clone https://github.com/zainabmambetkulovva/-7.git
cd проект7
```

### Шаг 2: Настройка переменных окружения
Создайте файл `.env` в корневой папке (или используйте значения по умолчанию):
```bash
cp .env.example .env
```

### Шаг 3: Установка зависимостей Backend
```bash
cd backend
npm install
```

### Шаг 4: Инициализация базы данных
```bash
npm run init-db
```

### Шаг 5: Запуск Backend сервера
```bash
npm start
```
Backend будет доступен на `http://localhost:5000`

### Шаг 6: Установка зависимостей Frontend (в новом терминале)
```bash
cd frontend
npm install
```

### Шаг 7: Запуск Frontend приложения
```bash
npm start
```
Frontend откроется автоматически на `http://localhost:3000`

## 📡 API Endpoints

### Транзакции:
- `GET /api/transactions` — получить все транзакции (с фильтрацией)
- `GET /api/transactions/:id` — получить одну транзакцию
- `POST /api/transactions` — создать транзакцию
- `PUT /api/transactions/:id` — обновить транзакцию
- `DELETE /api/transactions/:id` — удалить транзакцию

### Статистика:
- `GET /api/statistics` — общая статистика (доходы, расходы, баланс)
- `GET /api/statistics/categories` — статистика по категориям

### Утилиты:
- `GET /api/categories` — список всех категорий
- `GET /api/health` — проверка работоспособности API

### Параметры фильтрации:
- `type` — тип операции (income/expense)
- `category` — категория
- `startDate` — начальная дата (YYYY-MM-DD)
- `endDate` — конечная дата (YYYY-MM-DD)

## 💡 Использование

### Добавление транзакции:
1. Выберите тип операции (Доход или Расход)
2. Заполните название, сумму, категорию и дату
3. Нажмите "Добавить транзакцию"

### Редактирование:
1. Найдите нужную транзакцию в списке
2. Нажмите кнопку "Изменить"
3. Отредактируйте данные в форме
4. Нажмите "Сохранить изменения"

### Удаление:
1. Найдите транзакцию в списке
2. Нажмите кнопку "Удалить"
3. Подтвердите действие

### Фильтрация:
1. Используйте секцию "Фильтры"
2. Выберите тип операции, категорию или укажите период
3. Список транзакций обновится автоматически

### Просмотр статистики:
- Карточки баланса в верхней части страницы показывают общие суммы
- График отображает расходы или доходы по категориям
- Переключайте тип в фильтрах для смены данных графика
